# Product API
## A REST API implementation for managing products.

### This API provides basic CRUD operations:

Create — Add a new product. 

Read — Get one or all products. 

Update — Modify an existing product. 

Delete — Remove a product. 

The API exposes endpoints under /api/products and allows clients to manage product data through standard HTTP methods such as GET, POST, PUT, and DELETE. 

### This project is intended as a simple example of how a CRUD-based REST API works.
